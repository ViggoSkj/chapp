# chapp

Frontend repository for Chapp, a Mandarin learning application. The .NET Neuron
backend is maintained separately in
[ChappBackend](https://github.com/ViggoSkj/ChappBackend).

Start with the [frontend documentation map](frontend/docs/README.md) for
composition, exercise flows, and development checks. Read the
[agent instructions](frontend/AGENTS.md) before changing the app.

## Frontend

The Next.js application lives in `frontend/`.

```sh
cd frontend
pnpm install --frozen-lockfile
pnpm dev
```
